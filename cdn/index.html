deshiQR browser bundle

One file, no bundler, no build step: deshiqr.global.js exposes window.DeshiQR with exactly two functions — update(payload, edits) and validate(payload). It edits a Bangla QR payload and returns the updated payload. It does not render QR codes; encode the returned payload with whichever QR library you already use.

Use it

<script src="deshiqr.global.js"></script>
<script>
  const updated = DeshiQR.update(payload, { amount: 500, reference: "BILL123" });
  const report = DeshiQR.validate(updated); // { ok, errors, warnings }
</script>
