Update a Bangla QR payload in the browser

One script tag, no bundler, no build step for this page (it loads the locally built bundle). It applies edits to the payload and shows the updated payload string and any warnings. It does not render a QR code — encode or render the returned payload however you like.

Synthetic payload only. The account 01000000000 is deliberately unassignable and the NPSB tokens are dummy values. Never put a real merchant payload in a committed file — see docs/demo-payloads.md.
